# Portfolio data

Files for the COMP5001 portfolio. The assessment brief is on the [module website](https://sakibanwar.github.io/COMP5001-Artificial-Intelligence-26-27/).

## `deliveries.csv` (Part 1, problem 4: Late deliveries)

600 past deliveries, one per row. Columns:

| Column | Meaning |
|---|---|
| `distance_km` | length of the delivery in kilometres |
| `stops_before` | stops the van made before this one |
| `weight_kg` | weight of the parcel in kilograms |
| `rain` | 1 = raining, 0 = not |
| `rush_hour` | 1 = yes, 0 = no |
| `driver_experience_years` | the driver's years of experience |
| `late` | 1 = late, 0 = on time |

The data is made up for this assessment. About one delivery in three is late.

Problem 4 starts from the Week 7 program [`week07-learning/banknotes/banknotes0.py`](../week07-learning/banknotes/banknotes0.py). To download this file on its own, open it above and use the **Download raw file** button.
